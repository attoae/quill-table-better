# Security Policy

## Supported Versions

All 1.x releases receive security updates. Older releases are not supported.

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| 1.1.x   | :white_check_mark: |
| < 1.1.0 | :x:                |

## Reporting a Vulnerability

Please **do not open a public issue** for security vulnerabilities.

To report a vulnerability, use one of these channels:

1. **Private security advisory (preferred):**
   [Report a vulnerability](https://github.com/attoae/quill-table-better/security/advisories/new)
   — this requires "Private vulnerability reporting" to be enabled in
   Settings → Code security and analysis.
2. **Email:** contact the maintainer directly.

What to include in a report:

- The affected version
- A proof of concept
- A suggested fix, if you have one

What to expect:

- You will receive an acknowledgement within **7 days**.
- The report will be triaged within **30 days**.
- If accepted, a fix will be released within **90 days**, coordinated with
  CVE assignment via a GitHub Security Advisory.
- If declined, you will be told why.
- The reporter will be credited in the advisory unless they prefer to
  remain anonymous.
